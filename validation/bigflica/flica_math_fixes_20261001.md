# FLICA 数学错误修复与验收

本页记录 `f12dba7` 及之前的自由能修复和定位试验。后续已将默认 PCA 尺度和逐模态 W 先验改正，详见[初始化与先验修复](flica_initialization_prior_fix_real1000_20261001.md)。下文的“尚未替换”描述保留当时的实验状态。

## 已合并到本地实现的修复

对照 [官方 MATLAB FLICA 发布包](https://fsl.fmrib.ox.ac.uk/fsl/docs/utilities/flica_2013-01-15.tar.gz)及概率分布解析式，修复了以下问题。运行流程仍使用仓库 Python/PyTorch，不调用 MATLAB 或 FSL。

| 修复 | 修改后的行为 |
|---|---|
| 自由能最终求和 | 每个全局项和每个模态项只累计一次，不再依赖数组广播 |
| `sum_dims` | 保留未求和维度和原来的轴，支持概念单维广播；不再只取首元素 |
| H/W 高斯熵 | 使用 `1+log(2π)` |
| μ 高斯先验 | 使用负的归一化常数 |
| λ Gamma 先验 | 惩罚为 `−Eλ / prior_scale` |
| 加权似然 | 明确使用向量内积，`matrix` 与 `ndarray` 两种表示结果一致 |
| 求和与协方差辅助函数 | 保持 float64，消除 CPU 辅助函数隐式降精度 |
| `q log(q)` | 使用 `scipy.special.xlogy`，保留零概率的数学极限值 |
| 迭代次数 | CPU/GPU 均执行恰好指定次数，必须为正数 |
| 自由能历史 | 每次更新对应一项；未计算项为 NaN，最后一次保存实际 F |
| 保存终态 | 不论更新次数是否为 25 的倍数，均保存最后状态 |
| 直接体素 R 模式 | 公开接口将逐被试噪声设置传到初始化，并保存至独立的 `components_C_lambda_R` 目录 |
| 直接体素输出验收 | 与压缩流程共用有效秩 `1e-6` 和每模态拟合范数比 `1e-6` 检查，失败时保留诊断并阻止新模型和脑图生成 |

部分熵常数错误也存在于官方旧 MATLAB 包，修复使用解析分布公式；没有直接照搬其错误常数。源码中的 W 先验和默认初始化尚未替换，原因见下文。

## 验证

以下命令在带 CUDA 的本地环境通过 **67 项测试**：

```bash
PYTHONPATH=src python -m pytest \
  tests/test_bigflica.py \
  tests/test_flica_variational_math.py \
  tests/test_flica_cpu_gpu_updates.py \
  tests/test_bigflica_raw_routing.py -q
```

新增测试以 SciPy 分布熵、期望密度积分和独立高斯二阶矩核对公式，检查完整 CPU/GPU 更新及实际更新次数。生成的小矩阵仅用于数学回归测试；下面的精度验收使用真实数据。

### 30,000 人保存字典的真实修复控制

复用同一真实 CPU 字典、同一 CPU 初始后验，C20/R100/D200，R 噪声模式，CPU/GPU 均执行 1000 次更新，没有重跑影像加载、mMIGP 或 DicL。

| 检查 | 结果 |
|---|---|
| CPU/GPU 有效成分 | 均为 17，精确零行均为 12/14/16（一基） |
| H 相对误差 | 8.39e-15 |
| X/W/lambda 最大相对误差 | 4.55e-14 / 5.95e-14 / 5.06e-15 |
| 拟合矩阵最大相对误差 | 1.02e-13 |
| CPU 实际 F 历史 | 恰好 1000 项，全部有限 |
| F 首尾 | −126906.913320 → −108143.901192 |
| 999 个相邻 ΔF | 全部为正，最小 0.345746 |

另外，修复后 CPU 执行 1001 次更新，与旧版 cov64 相同次数结果的 H/X/W/lambda/拟合矩阵相对差均为零。这证明本次自由能诊断修复没有改变相同精度、相同迭代次数下的参数轨迹。

末尾 F 仍在上升，因此不能把达到 1000 次上限当作收敛。共享 GPU 下的 CPU F1/GPU/CPU F0 观测耗时为 25.90/32.37/21.60 秒，仅用于确认实验完成，不作为受控速度比较。

[聚合比较、1000 点自由能及产物核验](flica_math_fix_real30000_20261001.json)包含源码 SHA-256、输入字典 SHA-256 和保存状态核验。

## MATLAB 初始化是否恢复了成分

令加权拼接矩阵 `Z = concat(sqrt(DD[k]) * Y[k]) = U S Vᵀ`，总空间行数为 P。严格 MATLAB 初始化为：

- `X[k] = sqrt(P) * U[k, :C]`；
- `H = S[:C, None] * V[:, :C].T / sqrt(P * mean(DD))`；
- `W[k] = sqrt(mean(DD) / DD[k])`。

仓库现有数值初始化入口应传 `H_pre = S[:C, None] * V[:, :C].T / sqrt(P)`，这里 S 为奇异值向量。对应初始重建为每模态的 rank-C 投影，拼接 X 的每列 RMS 为 1。

四个真实字典控制保留原自动 DD、R 模式、1001 次更新，仅替换初始化及注明的 W 先验：

| 字典 | 设置 | 有效成分 | VBM/FA/MD 拟合范数比 |
|---|---|---:|---|
| CPU | MATLAB 初始化 | 5 | 2.88e-18 / 0.190886 / 0.184543 |
| GPU | MATLAB 初始化 | 7 | 1.01e-13 / 0.193253 / 0.221304 |
| CPU | MATLAB 初始化及逐模态 W 先验 | 5 | 3.19e-18 / 0.190876 / 0.184541 |
| GPU | MATLAB 初始化及逐模态 W 先验 | 7 | 3.50e-13 / 0.193234 / 0.221304 |

这些控制的 FLICA 引擎均为 CPU，GPU 只表示字典来源。数学初始化检查通过，但效果比原设置的 17/13 更差，未通过 C20，所以暂未替换默认。逐模态 W 先验也没有恢复成分。[完整控制记录](flica_matlab_init_controls_real30000.json)。

## 原始体素与后续压缩验证

按照用户指定的顺序，先对固定 1000 人、完整 VBM/FA/MD 掩膜直接运行 FLICA，再加入 mMIGP 和 DicL。官方 `flica_load` 默认每体素去均值后使用每模态整体 RMS；现有 FNIT 输入按每体素标准差缩放。本次生成了两种缓存，以下完整拟合针对整体 RMS，不替代公开默认预处理的验收。

原始体素基线已完成：同初态 CPU/GPU 100 次均保留 20 个有效成分，参数相对差最大 `1.65e-10`；独立 GPU 1000 次仍为 20，60 张原始被试空间 z-stat 图与独立 NumPy/SciPy 对照最大差 `1.91e-6`。[输入、阶段耗时、残差和限制](raw_flica_real1000_20261001.md)。

随后同输入 mMIGP 原投影/归一化投影仅保留1/19个成分，CPU/GPU DicL 后都为7；同字典、同初态两端退化一致。这些差异不能由修复自由能诊断消除。[压缩后的对照](compression_after_raw_real1000_20261001.md)。

直接体素 R 模式的噪声精度对应原始被试；字典 R 模式对应压缩坐标，统计含义不同。原始体素结果不能由已保存字典的失败结果替代。验收需同时报告有效成分、每模态残差、成分/脑图一致性及分阶段时间，并维持 C20 和既有阈值。
