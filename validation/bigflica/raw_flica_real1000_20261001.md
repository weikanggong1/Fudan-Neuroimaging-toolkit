# 原始体素 FLICA：1000 人基线

## 输入和模型

先运行原始体素 FLICA，再测 mMIGP 和 DicL 的影响。固定使用此前 30,000 人清单中的前 1000 人，不含 task 模态。清单 SHA-256 为 `da9126d2e13b624501fc3e88ae46e1dade2d978446333c96827d0ae12da1765c`；被试 ID、影像、后验数组留在私密验证环境。

| 模态 | 每名被试的文件 | 完整掩膜体素数 |
|---|---|---:|
| VBM | `VBM_2mm.nii.gz` | 157901 |
| FA | `dti_FA_2mm_mmorf.nii.gz` | 222257 |
| MD | `dti_MD_2mm_mmorf.nii.gz` | 222261 |

均为 `91×109×91`、2 mm 网格。同一模态所有影像与掩膜的形状、仿射一致，3000 幅输入均有限，无缺失被试或零方差体素。总计 602419 个体素。

本次按 MATLAB `flica_load` 的默认方式，每个体素跨被试去均值，再除以该模态所有去均值数据的整体 RMS。不是每个体素除以自己的标准差。VBM/FA/MD 的整体 RMS 分别为 `0.3107991 / 0.09255818 / 0.0003503122`。

请求 C20、逐被试噪声 `R`、自动 DD、严格 MATLAB SVD 初始化。自动 DD 分别为 `0.07485097 / 0.02908024 / 0.02509831`。共同完整初始状态 SHA-256 为 `44c6ed325bd9e7135637d883a1fdf7b595450a3390779e90bdce033b0ec995c5`。初始化重建与 rank-20 PCA 投影的相对差小于 `2.5e-15`。

CPU/GPU 均使用修复后的 float64 变分更新，不使用 float16。CPU 线程数为 8，GPU 为共享 H100；GPU 的 TF32 开关开启，但不改变 float64 运算。

## 同输入、同初始化、100 次完整更新

| 检查 | 结果 |
|---|---|
| CPU/GPU 有效成分 | 均为 20，阈值仍为最大奇异值的 `1e-6` |
| 精确零行 | 两端均为 0 |
| H 相对差 | `1.93e-11` |
| X/W 最大相对差 | `1.65e-10 / 3.69e-11` |
| 噪声精度相对差 | `6.14e-13` |
| 原始被试空间 t 脑图相对差，VBM/FA/MD | `2.33e-11 / 2.15e-11 / 2.00e-11` |
| 60 张 z-stat 图与独立 NumPy/SciPy 对照 | 最大绝对差 `1.91e-6`，最大相对差 `9.76e-10`，最低相关 `0.9999999999999993` |
| 输出 float32 z 值逐元素精确匹配 | 99.813%，其余存在微小数值差，不是全部位一致 |
| CPU 自由能 | 恰好 100 项，全部有限，99 个相邻增量均为正 |
| 自由能首尾 | `−369500027.60 → −32382381.88` |

脑图使用同一原始数据、带截距回归和 `df=1000−20−1=979`。另外固定同一伪逆与标准误矩阵隔离 CPU/GPU 矩阵算术，相对差约 `1e-15`。没有把压缩坐标的 `df=79` 脑图混入这项检查。

z 转换额外核对当前 main `3794a23` 的统计模块，源码 SHA-256 为 `02be27e7008bf06cd045eb496d3da2009fa6b099a1322241ba5eee03070f3186`。两端均按 float64 最小正规数处理极端尾部概率，与 SciPy 独立计算比较；这项补测没有重跑 FLICA。

| 模态 | 重建范数 / 输入范数 | 相对残差 `||Y−XWH||/||Y||` |
|---|---:|---:|
| VBM | 0.235846 | 0.962278 |
| FA | 0.394357 | 0.905158 |
| MD | 0.490910 | 0.859331 |

范数比不等于解释方差。VBM 没有出现此前字典试验中的整模态重建消失。

## 分阶段耗时与资源

| 阶段 | 秒 |
|---|---:|
| 逐被试读取并生成两套归一化缓存 | 132.37 |
| CPU 参考初始化及投影检查 | 73.03 |
| CPU 100 次参数更新，六段计时累计 | 842.81 |
| CPU 100 次拟合墙钟，含逐轮 F、诊断和保存 | 1528.30 |
| GPU 输入缓存载入 | 10.42 |
| GPU 100 次完整更新，含后验传入和结果回传 | 9.12 |
| CPU/GPU t 脑图比较 | 18.57 |

CPU 更新中，lambda 占 415.91 秒、X 占 307.65 秒、H 占 79.06 秒、W 占 37.84 秒，其他约 2.35 秒。F 和迭代杂项约 655.20 秒，单独脑图/残差诊断 27.98 秒。F 未被独立精确计时，不能把 655.20 秒全部称为 F 的耗时。

GPU 诊断运行器将 4.49 GiB 输入按体素块传入预分配的显存缓存，主机不装入完整模态。另用同一初态做 5 次更新，缓存与分块读取的 H、X、W、lambda、DD 输出完全相同。公开直接体素接口仍逐块读取 HDF5；这里的 9.12 秒是私密缓存运行器的结果，不是公开端到端 API 的耗时。

CPU 参考峰值 RSS 为 8.72 GiB；该参考在 1000 人规模装入 Y，不代表大样本 CPU 已实现外存计算。GPU 分配/保留显存峰值约 4.80/4.84 GiB，进程总显存采样峰值约 6.60 GiB。分配器上限不包含 CUDA 上下文，不能当作整个进程的硬显存上限。

共享设备、单次运行和不同计时范围下，这些时间属于观测；没有据此宣称全链或大样本的受控加速比。

## 延长至 1000 次原始体素更新

GPU 从同一完整初态独立执行 1000 次更新，未从 100 次结果简单续接。拟合耗时 87.69 秒、缓存载入 10.80 秒，仍为 20 个有效成分、精确零行 0，最小相对奇异值约 0.04717。

| 模态 | 重建范数 / 输入范数 | 原始输入相对残差 |
|---|---:|---:|
| VBM | 0.235318 | 0.962760 |
| FA | 0.393678 | 0.905889 |
| MD | 0.492314 | 0.859198 |

100 至 1000 次的 H 匹配相对差约 0.560；子空间最大主角约 60.21°，第二大约 26.33°，其余不超过 5.87°。早期结果尚未固定所有成分方向。GPU 未计算完整 F 历史，达到 1000 次也不等于已经收敛。

## 接入 DicL 时的比较口径

随后已在同一 1000 人输入上分别测原始投影、具有 DicL 相同归一化的投影，以及 CPU/GPU DicL 字典。维持 C20，记录每一步的有效秩、每模态残差、停止轨迹和耗时；原投影/归一化投影为1/19个成分，两端 DicL 后都为7。[独立压缩报告](compression_after_raw_real1000_20261001.md)。

原作者的 mMIGP 使用 `U=V×特征值`，输出 course 为 `U@H.T`。该谱加权表示与原始坐标的最小二乘逆投影不同；DicL 又会逐 PC 标准化。压缩模型通过 C20 后，验收时应同时比较原版 course、子空间变化和同一原始被试空间的回归脑图，并将 PC 空间脑图另列。当前六项压缩对照未生成最终脑图；不能只按不同自由度的 z 值差判断精度。

上述 MATLAB 预处理与初始化用于隔离原因。公开接口默认仍为逐体素 z-score 和原 BigFLICA 初始化，本次原始体素结果不能替代这些默认设置的端到端验收。
