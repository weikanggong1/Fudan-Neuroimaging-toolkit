## 对照定义

- 两端使用同一例真实 UKB 的双侧初始球面、脑沟图和 HCP 参考资源。
- 配置为四级 `AFFINE,DISCRETE,DISCRETE,DISCRETE`，`simval=3,2,2,2`，最大迭代数 `50,10,15,15`；控制网格、标签网格、应变项和提前停止规则相同。

- 配准耗时包含输入读取和球面/报告写盘，排除 Python 导入、CUDA 上下文初始化、离线精度计算及 BOLD 投影。冷、热调用与带 profiler 的调用分开。

## 已定位的差异

原版本忽略了输入的四级配置，并采用固定迭代安排。当前按官方 schedule 执行有限差分刚性更新、前级 DATA→原生球面→新 DATA/控制网格变形、BFS/测地距离标签顺序和两轮 alpha fusion；HOCR 降阶及 FastPD 联合优化保留规定搜索范围、迭代上限和提前停止规则。

官方三角形面积在构网时缓存，归一化坐标后不会重算。FNIT 现保存同一缓存面积。相同真实几何下，修复后归一化特征误差降至约 `5×10⁻¹⁶`，float32 特征逐位一致。

官方浮点配置为 `Option<float>`，再提升为 double。直接使用 Python double 会改变步长和应变系数。按官方精度读取 shear/bulk 后，同一真实几何、特征和标签的 2,560 项候选成本最大误差从 `4.03×10⁻⁷` 降到 `7.99×10⁻¹⁴`。局部算子检查和上述完整配准分别测量。

刚性初始化须保留每次实际旋转后的 SOURCE 坐标；用累积旋转矩阵重新生成坐标会丢失舍入历史。在真实调用中，GPU 标量除法与指数的舍入组合使 77 次成本中有 7 次相差最多 1 ULP，并通过顶点/边上的邻域选择放大。采用独立 C++ double 除法、libm 指数和原顺序累加后，全部 77 次成本及每次 40,962 个逐顶点值逐位一致；正式实现复测中，首级 DATA、控制点、参考和原生坐标逐位一致，首级总成本差约 `3×10⁻¹⁴`，首个标签提案全部成本的最大差约 `1×10⁻¹²`。检查点与源码哈希见 [定位记录](diagnostics.current.public.json)。这项修复位于 `fnit.msm`；surface pipeline 继续调用它，并保存最终球面质控。

HOCR 重复高阶项的合并顺序已修复。当前严格浮点编译配置的 [13,000 个单元用例](native_hocr.current.public.json)对官方 ELC→FastPD 标签均一致，包括重复项与接近并列的成本。该项是优化器回归测试，不作为真实脑配准精度结论。

离散提案的 Rodrigues 旋转还有一处独立差异。真实首轮两端所有标签均为零，但 GPU cross、三角函数及 3×3 乘法的舍入使 231 个控制点分量产生最大约 `6×10⁻¹³` 的偏差，第二轮成本随后分叉。相同官方控制点下，现有球面重采样逐位一致。FNIT 现复用每轮已有的 CPU 坐标副本，用独立 C++ 生成并缓存旋转矩阵，再在 GPU 应用所有标签；官方实际 162 个控制点的 1,458 个矩阵值与 label0/label1 坐标逐位一致，正常生产前两轮 SOURCE/控制点及标签也逐位一致。该缓存保持运算定义，每轮只增加一次小矩阵传输。

清理后的 [156 项回归测试](tests.current.public.json)全部通过，覆盖 MSM、扩展、配置传递、CIFTI 轴顺序及 volume 接口。此前额外公共 API 扫描为 204 通过、1 失败：main 上已有五个 SAMSEG nuclei 文件导入 `surfa`，触发静态禁止依赖检查。这些文件及测试与清理前版本相同，旧扫描在测试记录中单列。

## 复测

验证服务器准备私有 JSON，包含 `inputs`、`official_spheres`、`config_file` 以及可选 `projection`。`inputs` 为 L/R 两套 `MSMSulcInputs` 的文件路径；`projection` 使用同一固定 volume 和几何。正式测量前，独立运行官方 newMSM 生成参照球面。

```bash
python tools/benchmark_msmsulc.py \
  --case-json /absolute/path/case.private.json \
  --source-root /absolute/path/Fudan-Neuroimaging-toolkit \
  --output-dir /absolute/path/new-benchmark-directory \
  --device cuda:0 --warm-repeats 1 --profile-full
```

脚本调用 FNIT 配准与 Workbench 投影，不调用官方 newMSM。`report.safe.json` 保存来源哈希、实际配置、精度、阶段墙钟、CUDA kernel/同步事件及显存；输出目录中的球面和 CIFTI 为私有验证文件。

GPU 整卡利用率包含其他进程的负载；Torch 峰值已分配显存属于本进程。阶段计时为嵌套主机墙钟，CUDA kernel 时间单列，带 profiler 的时间不替代冷/热配准时间。

### 已修复的子函数差异

MSMAll 的边界邻域选择与球面 warp 使用包内独立 C++ 保留原版标量舍入和严格距离比较；默认 MSMSulc 不启用新增路径。权重下采样按官方定义先找包含三角形，再只比较其三个角点；距离完全相同时保留原三角形的角点顺序。全局最近顶点在非均匀球面上会选择另一个顶点，已在真实第三级权重检查中定位并修正。各项精确数值与源码哈希保存在上述定位记录。

权重面积还须区分官方的 Mesh 拷贝边界：拷贝构造与赋值会重建三角形，并在当时的坐标上重新计算面积。参考权重重采样使用归一化的 regular DATA 面积；绝对权重重采样使用当前 SOURCE 与当前控制网格的面积。此前两处都沿用固定构网面积，现已在 MSMAll 子函数内修正。特征初始化的原始面积缓存、VN 与默认 MSMSulc 路径保持原定义；公开算子用例与真实三级配准分别验收，不把合成用例作为 benchmark。

真实第 2 级检查点确认该因果：第 1 级结束的 SOURCE/控制网格、第 2 级进入求解的 SOURCE/控制网格、标签 0/1 坐标及三角形索引均与官方 float64 逐位一致。只修正两处面积定义后，合并权重的最大差从 `3.887e-5` 降至 `6.66e-16`，控制点绝对权重从 `0.020014` 降至 `9.99e-16`；10,240 项候选成本的最大差从 `0.004023` 降至 `8.29e-10`，修复后 MAE 为 `1.97e-13`。全部候选成本转换为 float32 后一致，零标签成本按官方顺序累加为 `496.05739459784087`，逐值匹配。上述完整三级球面和全帧时序复测随后通过。

[公开面积单测](../../tests/test_msmall_copy_area.py)使用实际官方 SDK 生成的 [162→42 顶点、三列非恒定权重用例](../../tests/data/msm_multivariate_copy_area.json)。当前坐标的顶点面积与 SDK 拷贝缓存逐值相同，重采样最大误差为 `2.22e-16`；此前固定面积的最大误差为 `2.79e-4`。这项检查锁定算子定义，不用于衡量真实脑数据的速度或精度。

独立 Python 进程首次调用时，MSMAll 和共享 MSMSulc 入口还可能在 CUDA 初始化前重置显存统计而报错。现在先初始化 CUDA，再开始配准计时与统计；两项新进程调用测试通过，配准数学未改。旧验证 BOLD 的空间单位为 `unknown`，本次固定投影输入仅在仿射和形状逐值匹配同源 T1 的毫米网格后，修正单位字段为 `mm`；体素数据、仿射、形状和时间单位不变，原文件保留。配准错误与输入头来源分别记录。

### 复测 MSMAll

服务器私有清单含 `inputs`、`official_spheres` 与 `config_file`；可选 `projection` 使用固定 volume 和几何。32k 特征还须提供 `native_projection_basis` 的双侧原生 MSMSulc 球面，用于相同方式的变形合成。先在独立参考环境运行官方 newMSM 生成球面，再运行：

```bash
python tools/benchmark_msmall.py \
  --case-json /absolute/path/msmall.case.private.json \
  --source-root /absolute/path/Fudan-Neuroimaging-toolkit \
  --output-dir /absolute/path/new-msmall-benchmark-directory \
  --device cuda:0 --execution optimized --threads 4 --warm-repeats 1
```

脚本不调用官方 newMSM；`report.safe.json` 保存汇总精度、耗时和来源哈希。个体输入清单、球面、逐点成本和 CIFTI 留在验证服务器。一级和三级配置分别运行，执行方式对照使用 `--execution reference`；不能将不同科学配置的耗时作为同算法加速比。
