# 原始 UKB DWI 的 BIDS 入口：真实端到端检查

用户提供的同一受试者 AP/PA 原始 DWI、bval/bvec、T1w 和已经完成的官方 FreeSurfer subject 是本次输入。测试时将原始文件按 BIDS 命名组织到私有目录；受控影像、个体矩阵和脑图不纳入公开仓库。FNIT 0.16.0、PyTorch 2.5.1 和共享 NVIDIA H100 PCIe 是运行环境。独立的公开数据脑图与官方参考比较见 [ds004666 七 atlas](ds004666/seven_atlas_100k_20260929.md)和[三次追踪重复](ds004666/tracking_100k_three_seed_20260929.md)。

```bash
UKB_BIDS_ROOT=/private/ukb_bids                 # 同一受试者原始 AP/PA DWI、bval/bvec、JSON 和 T1w
FREESURFER_SUBJECT_DIR=/private/subjects/subject # 已完成的官方 recon-all subject
OUTPUT_DIR=/private/fnit_connectome             # FNIT 私有输出与断点状态
fnit UKBConnectome_pipeline \
  --bids-root "$UKB_BIDS_ROOT" --subject SUBJECT --direction AP \
  --freesurfer-subject-dir "$FREESURFER_SUBJECT_DIR" \
  --atlas fs-aparc --n-seeds 100 --seed 0 --device cuda:0 \
  --output-dir "$OUTPUT_DIR"
```

此小规模运行检查接口和数据流，100 次播种不能用于生物学连接强度推断。BIDS 选片读取了 105 卷 DWI 和反向相位编码图像；PyTorch TOPUP、EDDY、响应估计、MSMT-CSD、mtnormalise、5TT/GMWMI、TorchFLIRT、ACT/iFOD2、SIFT2 与四矩阵均运行完毕。已有 FreeSurfer subject 直接使用，真实运行没有重新执行 `recon-all`。

| 检查 | 实测 |
|---|---:|
| 退出状态与总墙钟 | 0；3,570 s，包含预处理、DWI 重建与矩阵写盘 |
| EDDY DWI 八次迭代 | 最后一轮累计 856.8 s，见私有运行日志 |
| PyTorch 峰值分配 | 4.542 GiB；不包含 CUDA 上下文及其他进程显存 |
| 播种尝试 / ACT 接受 | 100 / 14 |
| DWI 网格和 atlas | 104×104×72；背景 0、节点 1–84 均出现 |
| 四矩阵 | 每张 84×84、数值有限且严格对称；`nodes.tsv` 有 84 行节点 |
| 同输入第二次运行 | TOPUP、EDDY、connectome 均跳过；4.06 s；四张矩阵 SHA-256 前后相同 |

同一官方 FreeSurfer 压缩包的 `aparc.a2009s+aseg.mgz` 与双半球 `.annot` 还验证了第二套原生 atlas。FNIT 在 H100 上将 617,430 个纳入的体素连续编号为 164 个节点，逆向映射回原始 FreeSurfer ID 后错误体素为 0；更新后实测 1.037 s、PyTorch 峰值 0.406 GiB。

随后以首次运行产生的校正 DWI 与旋转梯度作为已完成的预处理输入，单次调用选择 `--atlas fs-aparc fs-aparc-a2009s`，共用一次响应估计、FOD、追踪和 SIFT2。真实运行退出码为 0，耗时 6,159 s、PyTorch 峰值分配 2.687 GiB；100 次播种接受 24 条。两套输出分别有 84 和 164 个 `nodes.tsv` 节点，`atlas_dwi.nii.gz` 的标签分别完整覆盖 `0..84` 和 `0..164`；各自四张矩阵的尺寸正确、数值有限且严格对称。相同参数再次调用在 3 s 内跳过 connectome，八张矩阵的 SHA-256 均保持不变。该 H100 为共享设备，运行时两张卡利用率均达 100%，两次墙钟不能据此解释为 atlas 数量的性能增量。

双 atlas 独立重算的 `fs-aparc` 矩阵与首次原始 BIDS 全链结果并不逐文件相同。两次使用同一校正 DWI，脑掩膜和 FA 输出文件相同，5TT 体素数组相同；但 DWI→T1 刚体变换在脑掩膜内产生平均 0.231 mm、95% 分位 0.428 mm 的世界坐标位移，使 6,542 个 DWI atlas 体素标签改变。首次和双 atlas 运行分别接受 14 和 24 条流线。续跑哈希不变只证明跳过机制正确，不能视为独立重算一致。此差异仍需冻结同一配准矩阵，分别评估 GPU 配准的重复性和追踪随机变化。

在相同 H100 软件环境下执行 `PYTHONPATH=src:. python -m pytest tests/connectome -q`，102 项测试通过。

该受试者的官方 FSL/MRtrix 全链**尚未在同一原始 DWI 上重新运行**，因此上表是端到端正确执行与续跑证据，不是输出一致性结论。旧的真实数据固定轨迹对照显示七套 count 矩阵逐元素一致；独立追踪的部分长度、端点和 TDI 指标仍未全部进入 MRtrix 自身三次重复范围，见上方公开数据报告。采样诊断在本次运行的 MSMT-CSD 活跃集求解中观察到频繁 GPU 同步；3,570 s 也不应解释为与官方软件的配对速度比。
