# 10 例真实 T1 的脑图规则

`plot_cohort.py` 只读已完成的公开 T1、官方标签、FNIT 标签和 `analyze_cohort.py` 输出。只使用 CPU 的 `numpy`、`scipy`、`nibabel`、`matplotlib`；不运行分割，不调用外部神经影像程序，不使用 AI 绘图。

## 固定选择

绘图包括 `sub-01` 的连续性例子、全队列 `raw_native` 的总体加权 Dice 中位病例和最差病例。总体指标包含全部 110 标签，按官方原网格体素数加权；分数从低到高排序，平分时按 `case_id` 排序，偶数病例使用较低的中间名次。三个角色重复选中同一病例时，只绘制一次并列出其所有角色。

`plot_manifest.json` 保存全部 10 例的排名、开发标记、110 标签的有效数量和 NA 数量。失败或总体指标未定义的病例仍保留为 NA，附原因；不把 NA 记成零，也不根据图像外观选择病例。缺少 `sub-01` 的真实结果时，连续性图明确不生成。

判断以已经独立审计的 `raw_native` 结果为单位；某病例同阶段模式失败时，其完整原始 T1 结果仍可用于原始 T1 图。准备阶段已终结的依赖阻塞记录单列保留，不误当作尚在运行的任务。

## 计数、空间及显示

1. 读取结果 SHA 与 cohort manifest 绑定的真实输入，逐项检查文件大小及 SHA。
2. 使用最近邻将官方原网格标签映射到该病例公开 T1 的真实 NIfTI 网格。右海马/杏仁核只对非零官方标签加一次 `10000`。
3. 在完整原网格逐一复核 110 标签的官方/FNIT 体素数、交集和 Dice；与 analyzer 不符时停止绘图。
4. 分别绘制脑干、丘脑、双侧海马、双侧杏仁核。每张图的三个比较行是官方、FNIT 和红色标签 ID 差异；两种方法细标签颜色完全相同。
5. 每个区域使用双方前景并集的局部 RAS 坐标范围，XY 加 8 mm 边缘；不输出完整头部或完整扫描平面。XY 超过 140 mm 时明确报错，不静默裁去异常标签。
6. 六张真实轴向切片使用前景并集的 RAS Z 坐标固定分位数：5%、23%、41%、59%、77%、95%。显示平面为 0.6 mm；T1 线性插值，两种标签均最近邻，不优化任何变换。
7. 六张固定局部切片中正 T1 强度的 2%/98% 分位数作为该图的唯一灰阶窗；所有比较行、所有切片使用相同窗。图注标明 Dice 在原始体素网格计算，不在显示像素计算。

标题给出病例、选择角色、总体名次和加权 Dice；双侧区域另给左/右 Dice。页脚列出该区域最低的三个有定义 ROI Dice 及双方实际体素数。颜色热图始终保留 10 个病例行、6 个家族列和固定 0–1 范围；NA 用灰色和 `NA` 标注。

## 调用及产物

仅在 FNIT 与官方队列均为终态、10 例审计均结束且没有运行中的尝试时调用。`--root` 必填；另外三个参数可省略，默认位置如下：

```bash
python plot_cohort.py \
  --root /path/to/ten_public_t1_20261002 \
  --manifest /path/to/ten_public_t1_20261002/cohort_manifest.json \
  --analysis-dir /path/to/ten_public_t1_20261002/analysis \
  --output-dir /path/to/ten_public_t1_20261002/brain_figures
```

产物为最多 12 张 `sub-XX_<区域>_raw_native.png`、`cohort_raw_native_family_dice.png` 及 `plot_manifest.json`。清单记录脚本、cohort、analysis、输入影像、分割结果和 PNG 的 SHA，真实排名、切片坐标、裁切范围、灰阶窗、调色板、110 个原网格 ROI 的独立复核。已有图片或清单的输出目录不会被覆盖。

脚本已通过 Python 解析、CLI 和 5 项选择规则的纯元数据检查。这些检查不使用任何模拟影像，也不作为真实 benchmark 结果；实际脑图须等待完整真实队列结果。
