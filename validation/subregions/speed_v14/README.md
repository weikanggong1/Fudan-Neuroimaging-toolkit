# v14 候选：粗网格初始化与精修预算

该候选在 v13 基础上恢复全部原分辨率精修级别，将 1 mm 粗阶段缩短为 2 轮、每轮最多 8 次网格更新。新增网格索引批量构建。两个完整流程使用冻结源码 `5ec927e`，后续发行配置已修订。

原始 T1 完整计算为 **16.21 min**，历史 v12 为 **41.33 min**。右海马相对 v12 的硬/软体积仍增加 **7.45%/8.27%**，对官方前景 Dice 为 **0.8599**（历史 0.8865）；右杏仁核为 **0.8397**（历史 0.8780）。四项最终网格 Jacobian 均为正，原始 T1 全部 110 项软体积完整；29 项几何、源码及输出检查不代表精度达标。

相同阶段输入的完整计算为 **33.74 min**，历史 v12 为 **45.02 min**。左海马硬/软体积相对 v12 增加 **9.55%/8.61%**，右海马增加 **7.57%/6.61%**；逐标签官方严格门槛的达标数从 26/103 降到 5/104。四项最终网格 Jacobian 均为正，28 项输入、源码和输出检查通过，全部 110 项软体积保留。该候选的整例精度回退，因此后续配置取消粗初始化并恢复完整外层日程。

## 调整依据

右侧前两个精修级别均完成所有 36 次网格更新，说明更新预算被用满。日志不含每轮成本或停止原因，无法据此量化离收敛还有多远。新版保留完整原始阶段日程，并增加网格更新预算。

粗拟合会改变精修起点，代码也会根据变形后的网格重新生成精修掩膜。日志实读发现，旧版和 v14 的精修有效体素数分别为丘脑 726560、左侧 538082、右侧 536019，完全相同；体素数量相同不保证逐点相同，但不能宣称实际掩膜已改变或是主要回退原因。三个粗初始化合计增加约 170.92 秒，新版取消该阶段，直接保留原精修图像、超先验与起点。

## 可复用的计算优化

[真实 CPU 索引比较](index_csr_real_cpu.json)：旧 FNIT 保存的丘脑和左海马网格上，候选数组、顺序及 hash 相同，预热后的 3 次交替测量中位耗时比为 **4.27/4.02**。新 CPU 临时分配峰值约 111/113 MiB；最终索引大小不变。该结果只覆盖索引组件，不能作为整例加速比。

[实际安装包审计](packaging_audit_v14.json)：正常构建 wheel 与 sdist，旧 GEMS Python/C++ 后端、构建器及专用环境均被排除；统一入口和输出模块包含在归档。该审计验证包包含范围，不验证后续数值日程。旧代码在源仓库保留，历史验证未删除。
