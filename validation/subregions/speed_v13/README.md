# v13 快速候选：完成验证后修订

同一个公开脱敏 T1（OpenNeuro ds000114、sub-01）完成了全部四类结构，分别复用官方阶段输入和从原始 T1 开始。计算源码为 `3ea8163`，最终发行默认配置已进一步修订，本文保留这一候选的结果。

| 流程 | 历史 v12 | v13 | 观测耗时比 |
|---|---:|---:|---:|
| 相同 norm/aseg/wmparc | 45.02 min | 33.55 min | 1.34 |
| 原始 T1 全流程 | 41.33 min | 23.41 min | 1.77 |

共享 H100 上的观测。29 项检查核对输入、源码、标签表、几何和完整输出，不是精度验收。完整逐标签精度与软体积保存在两个运行目录的 `comparison.tsv` / `report.json`；右侧标签统一加 10000。

速度提升伴随右侧结构偏移，不能据此采用该候选作为最终默认。v13 用 1 mm 第一平滑级别替代原分辨率第一轮精修；新的方案恢复全部精修，粗网格只做短暂初始化。

| 六个主要结构 | 阶段输入：对官方前景 Dice | 原始 T1：对官方前景 Dice |
|---|---:|---:|
| 脑干 | 0.9933 | 0.9358 |
| 双侧丘脑 | 0.9611 | 0.9067 |
| 左海马 | 0.9500 | 0.8920 |
| 左杏仁核 | 0.9532 | 0.8649 |
| 右海马 | 0.9014 | 0.8574 |
| 右杏仁核 | 0.9104 | 0.8382 |

v13 相对 v12 的阶段输入右海马硬体积增加约 8.0%，原始 T1 增加约 7.4%；阶段输入右海马对官方 Dice 从 0.9735 降至 0.9014，原始 T1 从 0.8865 降至 0.8574。原始 T1 的上游粗分割与官方输入有差异，其指标应与阶段输入分别解释。

## 计算组件

真实保存的旧 FNIT 丘脑和左海马网格上，compact 栅格化、共用几何和解析梯度的成本与覆盖没有观察到差异，梯度相对 L2 差异分别为 `8.52e-7` 和 `3.94e-6`。预热后成本及反向传播中位耗时比为 12.81 和 22.81；这是固定网格组件比较，不是整例加速比。FP32 开启 TF32，完整记录见 [组件报告](components/summary.json)。
