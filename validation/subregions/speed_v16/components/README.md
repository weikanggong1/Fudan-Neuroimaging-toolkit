# 亚区分割 GPU 组件实测

本页记录 `v16_c2` 组件优化，以及 `v16_c3` 的网格归属复用验证。使用同一真实 `sub-01` T1 的既有网格和 `norm/aseg/wmparc` 输入；运行中仅读取已保存的官方结果，不调用 FreeSurfer。服务器为 gpucw1，物理 GPU 1 为共享 H100 PCIe，4 个 CPU 线程，PyTorch 2.5.1，FP32 与 TF32。

汇总数值见 [component_summary.json](../component_summary.json)。本地归档中的 13 个组件文件和 8 个候选运行文件均已核对大小与 SHA-256；源码冻结清单的服务器核验也全部通过。

本页为早期组件记录；整例结果与最终 C6 方案见[完整验证](../README.md)。其中汇总 JSON 的 pending 字段反映写入当时的状态。

## 哪些计算仍不利于 GPU

| 模块 | 原路径的成本来源 | 本次处理及实测范围 |
|---|---|---|
| 网格 likelihood 与梯度 | 插值 prior、归一化、logsumexp 及四顶点梯度分为多个算子，保存大量中间 tensor | Triton 融合数据项及解析顶点梯度；完整有效体素静态网格对照见下表 |
| alpha 平滑 | 每层重做参考网格 raster；GPU prior 转到 CPU，用 SciPy 平滑，再传回 GPU | 参考网格 raster 在同一几何与 class 配置下复用，平滑和 10 次 alpha EM 留在 GPU |
| 海马薄层的强度先验 | CPU raster 后做 Gaussian filter 与 KDE | raster/filter 移到 GPU；原网格组织取样和 KDE 仍在 CPU |
| 脑干粗网格 | 每步生成整个 crop 的 prior，使用独立几何与通用 autograd 先验 | 只计算固定侵蚀 mask 内的点，复用几何，使用解析形变先验；保留原 40 步 |
| 每个试探位置的 cell 搜索 | 每次 line search 都重新比较每个点的候选 tetrahedron | c3 复用严格内部点的上次 cell，边界点继续完整搜索，并周期性刷新 |

这些模块还受 CPU 控制流程、line search 次数、index 重建及共享 GPU 负载影响。下面测的是各自明确范围的组件，不把各项相加或用组件速度比推算整次分割耗时。

## 静态网格：融合数据项

两组实验均保留全部有效体素，`sampling_stride=1`。每组第一次调用单列；预热中位数来自随后 3 次测量，并交替执行 autograd 与 fused 路径。

| 真实保存网格 | 有效体素 | 首次 autograd / fused | 预热 autograd / fused | 预热观察比值 |
|---|---:|---:|---:|---:|
| 双侧丘脑 | 717,531 | 1.619 / 2.227 s | 0.11123 / 0.06643 s | 1.67× |
| 左海马＋杏仁核 | 526,626 | 0.525 / 0.635 s | 0.04483 / 0.02186 s | 2.05× |

首次调用包含分配、编译和 cache 建立，fused 首次耗时在两组中均更长。预热测量只覆盖固定网格上的数据项和形变先验目标及 backward，不包含 EM、预处理、优化器迭代或输出。

| 网格 | 最大梯度相对 L2 差异 | 最大单元素梯度差异 | 数据项／目标／先验／最小 Jacobian 差异 |
|---|---:|---:|---|
| 丘脑 | 1.47×10⁻⁷ | 0.00024414 | 4 次对照均为 0 |
| 左海马＋杏仁核 | 1.35×10⁻⁷ | 0.00097656 | 4 次对照均为 0 |

所有梯度均为有限值。原始报告的 `numerical_gate.passed=true`，`enforced=false`；它记录数值结果，没有用该 gate 中断运行。

| 内存指标 | 丘脑 | 左海马＋杏仁核 |
|---|---:|---:|
| autograd CUDA tensor 峰值 | 0.720 GiB | 0.541 GiB |
| fused CUDA tensor 峰值 | 0.251 GiB | 0.226 GiB |
| 整个组件进程采样占用峰值 | 2670 MiB | 1640 MiB |

CUDA tensor 峰值来自 PyTorch `max_memory_allocated`。进程峰值来自约每 5 秒的 `nvidia-smi` 采样，包含 CUDA context、allocator 等占用，不能替换 tensor 峰值。短组件的采样也不能描述每一次毫秒级测量期间的 GPU 负载。

原始结果：[丘脑](v16_c2_fused_thalamus.json)、[左海马＋杏仁核](v16_c2_fused_hippo-amygdala-left.json)、[串行组件状态](v16_c2_components_status.json)。

## alpha 平滑：先区分首次 raster 与缓存复用

每种网格先执行 sigma=1.5，建立参考 raster cache，再执行 sigma=0.75。参考顶点、tetrahedron、alphas 与 Gaussian classes 不变时，可以复用其 prior、覆盖、cell 及权重。各项只测一次，下面不是多次运行中位数。

| 网格与 sigma | 原路径总时间 | 新路径总时间 | 原／新 raster 时间 | 原 CPU／新 GPU 卷积时间 |
|---|---:|---:|---:|---:|
| 丘脑，1.5，首次 raster | 5.512 s | 7.115 s | 4.739 / 6.953 s | 0.410 / 0.026 s |
| 丘脑，0.75，复用 raster | 13.025 s | 0.138 s | 12.327 / 无需重做 | 0.371 / 0.016 s |
| 左海马，1.5，首次 raster | 18.733 s | 15.129 s | 16.969 / 14.832 s | 1.083 / 0.178 s |
| 左海马，0.75，复用 raster | 16.491 s | 0.170 s | 14.955 / 无需重做 | 0.949 / 0.025 s |

首次丘脑 raster 的新路径更慢；sigma=0.75 的大幅下降主要来自避免重复 raster。旧路径平滑卷积本身只占约 0.37–1.08 秒，原 preparation 中的大头是 raster 与其他处理，不能全部归因于 CPU 卷积。

| 网格与 sigma | alpha 最大绝对差异 | alpha 平均绝对差异 |
|---|---:|---:|
| 丘脑，1.5 | 2.98×10⁻⁷ | 3.97×10⁻⁹ |
| 丘脑，0.75 | 4.17×10⁻⁷ | 2.94×10⁻⁹ |
| 左海马，1.5 | 7.47×10⁻⁵ | 3.01×10⁻⁷ |
| 左海马，0.75 | 2.32×10⁻⁴ | 3.45×10⁻⁶ |

各节点 alpha 和的最大误差均不超过 2.98×10⁻⁷。这些差异覆盖 GPU 卷积、分块责任统计与 10 次 alpha EM 整条新路径，不是单独 cache 操作产生的差异。

## 海马薄层强度先验

真实左海马的完整 hyperparameter preparation 从 **27.435 秒降到 17.966 秒**。其中 CPU raster 为 18.119 秒，新 GPU raster 为 10.293 秒；其余处理合计从 9.316 秒变为 7.673 秒。组织取样与 KDE 仍在 CPU。

Gaussian hyper-counts 完全相同；13 个 hyper-means 的最大绝对差异为 **0.00291443**，仅薄层相关的两个 mean 发生变化。原路径的 CUDA tensor 峰值为 0.031 GiB，不能代表它在 CPU 上的 raster tensor/RAM；新路径 CUDA tensor 峰值为 0.745 GiB。整个 preparation 进程的采样占用峰值为 3134 MiB。

原始结果：[preparation](v16_c2_preparation.json)。

## 脑干：同一几何差异与完整 40 步终态分别报告

输入为真实同人的 `norm.mgz`、`aseg.mgz`，两条路径共用一次 affine 对齐，保留相同侵蚀 mask、目标、Adam 参数及 **40 步**。旧脑干函数从 v15 源码加载，两条路径共用当前 raster/deformation 依赖，因此它比较的是脑干调用路径迁移。

在同一初始几何、161,509 个有效体素上，数据项相同，目标绝对差异为 0.001953125，梯度相对 L2 差异为 **1.49×10⁻⁷**，最大单元素差异为 9.16×10⁻⁵。同一几何的首次单次耗时为 0.558 / 1.291 秒，包含初始化效应，不作为预热速度比。

| 完整粗网格拟合指标 | 原路径 | 新路径 |
|---|---:|---:|
| 40 步墙钟 | 19.080 s | 7.134 s |
| 粗目标 mask Dice | 0.971850 | 0.971719 |
| 最小 Jacobian | 0.328588 | 0.219962 |
| 终态按原 dense 目标重新评价 | 10458.0049 | 10466.6094 |
| CUDA tensor 峰值 | 0.272 GiB | 0.196 GiB |

完整组件的观察时间比为 **2.67×**。终态顶点的平均 L2 位移差为 **0.05556 voxel**、最大 L2 差为 **1.23436 voxels**；终态目标增加 0.0823%。两条路径均保持正 Jacobian，末态不逐顶点相同。同一初始几何的目标和梯度接近，并不保证 40 步后的网格或最终分割完全一致。本项没有进行强度拟合和最终原网格标签比较。

整个脑干组件进程的采样占用峰值为 1344 MiB。原始结果：[brainstem](v16_c2_brainstem.json)。

## c3：真实丘脑网格上的 cell 归属复用

使用真实保存的丘脑网格，4 次重复，每次施加 16 个受控、平滑的顶点位置变化。此项验证复用搜索的行为，不是一次实际拟合的收敛轨迹。

此次 `sampling_stride=4` 选中 **179,378 / 717,531** 个有效体素，数据项乘固定权重 **4.00010592**。几何、likelihood 和梯度保持 FP32/TF32，数据项标量求和使用 float64。两条对照都使用相同采样与求和配置，比较完整候选搜索和归属复用，不比较采样与完整体素积分。

预热中位数为 **0.02926 → 0.02301 秒**，观察比值 1.27×；排除首次重复及每轮第 0、8 个 index reset/完整刷新位置。首次 hint 编译调用达 5.594 秒；CPU index 重建另有 0.305–0.350 秒，均不能用预热值代替。

64 个位置中 cell 归属与覆盖差异均为 **0 个点**，目标与最小 Jacobian 差异均为 0，最大梯度相对 L2 差异为 **2.31×10⁻⁸**。该复用假设局部 cell 没有全局重叠；严格内部点之外仍完整搜索，并定期刷新。它需要整次拟合的输出验证。原始结果：[moving mesh owner](../candidates/v16_c3_owner_thalamus.json)。
