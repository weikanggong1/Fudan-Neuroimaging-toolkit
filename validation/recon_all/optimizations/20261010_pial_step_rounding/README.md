本记录对应源码基线`eae29511`加本次`place_surface_step._step`范数精度修复。
实际测试代码由各报告的导入模块SHA-256绑定；随后中文docstring变更不改变
已测试数学语句。参考是同机独立Conda固定源码构建，不是系统官方发行程序。

输入为公开ds000114两例的FNIT自产检查点，不是原始T1整例。生产算法不读取
原生输出；完整API返回后才打开隔离原生参考做QC。原始输入、程序、源码、
脚本和各完整私有报告SHA在[机器可读报告](complete_report.json)内。

## 错误原因与复现

旧实现把float32范数平方和升double后开方，固定Conda源码的实际重载先返回
float32再赋double。首步六项梯度一致而1417个接受坐标元素不同；39步轨迹
将此误差传播到退化局部，旧LH最后max2.838423mm/901顶点>0.1mm。
修复只改变开方晋升顺序，保留原有有序碰撞、拒绝重试和完整清理。
