## 显存与验收状态

目标 GPU 整卡采样峰值分别为 **24,428,675,072** 和 **63,715,672,064 字节**，均包含外部进程。FNIT 自身父子进程的同时占用峰值因进程归属未解析，均记为 `null`；20,000,000,000 字节预算尚不能判定。GPU 租约的原退出审计因无法识别异 UID 外部进程而失败；原回执状态保留，与两例科学作业的退出 0 分开记录。

本轮分别确认了**执行完成、138 项输出完整、生产网格门通过**，v2 事后比较也完成了分区 Dice、双向表面距离、脑区体积、独立网格质量与局部异常检查。严格逐文件复现未通过；整体指标等效没有事先确认的阈值，优化是否引入受控退化以及同环境整例提速均为 `not_assessed`，不以成功退出或平均脑区误差替代这些判定。
