## 原因与变更

先做相同真实输入的原样调用及同输入cProfile重复。原样42.611秒、
剖析48.609秒，标记完全相同。剖析中源谓词仅1.232秒；原逐面
`np.asarray`约24.7万次、`all`约74.1万次、`sum`约24.7万次。
本次保留原KD树与完整批次，将过滤打包CSR后原序编译；旧逐面实现已
从生产模块移除，冻结旧FNIT文件仅留服务器诊断参照。

19项focused契约覆盖原NumPy距离等值/±1ULP、整数桶边界、冻结面、
共享顶点、批次起点、单方向标记和实际MHT共享门；通过6.16秒。
契约不作为真实数据benchmark替代。
