# 拓扑候选热点：本轮证据

本目录对应有序邻接和完整状态装配两项优化。输入为公开 ds000114 sub07 ses-test 左半球、FNIT `79a41cdd` 自产上游；冻结诊断属性和先验明确作为单阶段输入。它不是原始 T1 整例，也不是完整种群搜索。

## 文件与范围

- `profile_v2.json`：一次真实完整 cProfile 的去敏收据，区分全局准备、候选几何和状态装配；旧启动器 v1 导入失败记录保留。
- `readonly_profile_v2.py`：实际执行的只读 v2 程序原字节。它通过 `FNIT_CACHE_ROOT` 查找相位明确的冻结工作区和输入，先核对旧源码清单；输出私有原始 pstats/JSON。固定 v2 运行目录必须不存在。再次执行应另建诊断版本并记录新程序 SHA，不能覆盖这次产物。
- `abba_v1.json`：控制/候选/候选/控制四个 fresh Python 子进程的完整收据。每进程完整运行两条候选与最终写回序列，保留原始四次时钟、每次实际加载源码 SHA 和 162 个完整状态字段门。
- `summary.json`：由 ABBA 原始记录计算的中位数、局部父项和完整 CLI 边界；没有将 cProfile 时钟当作配对控制。
- `contracts.json`、`contracts.xml`：15 tests + 7 subtests，10.00 秒；覆盖有序邻接、F32 求和次序、容量尾部、动态前缀校验和别名。这些是本地合同，不是真实影像 benchmark。
- `ARTIFACT_MANIFEST.json`：本轮两项源码、测试、工具、说明与报告的 SHA-256/大小；不包含清单自身。

## 实际结果

四个子进程均 EXIT0。所有首候选参考门、A/B 末态重复门，以及新旧完整状态/容量字段/控制轨迹均逐字节一致。只改变两个 FNIT 模块，其他实际加载 FNIT 模块的 SHA 全部相同。

完整 fresh CLI 本组中位从 **140.054776 秒到 105.166850 秒，缩短 24.91%**；有序邻接总时间中位从 38.028622 秒到 4.096078 秒，完整状态装配总时间中位从 9.183328 秒到 4.830166 秒。嵌套函数和 API 时间不能相加。四核、四线程、CUDA 隐藏；不使用 GPU，显存记录为 `null`。CPU 峰值仅在 cProfile 运行中测量，新 ABBA 未单独采样峰值。

这是一次共享主机的同输入 ABBA 观察，包含导入、首次 JIT、加载、完整计算、写出及比较。全局准备不按候选数重复计收益；完整 GA、完整网格质量、整例十分钟目标、干净安装和整体指标等效未在本目录判定。正在运行的旧源码完整搜索不回标成这两个优化的验证。

## 复现入口

使用 [完整中文说明](../../../../docs/recon_all/TOPOLOGY_CANDIDATE_HOTSPOTS.md) 第 3 节的具名参数命令：`tools/benchmark_recon_topology_candidate_hotspots.py` 接收两个冻结源码工作区、三个 before/global 输入、三个自产原始 MRI/表面输入、三个仅事后读取的参考和一个空输出目录。它核对旧工作区清单，并验证候选覆盖文件的实际加载 SHA。

输入和原始私有日志留在授权 benchmark 目录，公共报告仅保留输入大小/哈希、代码版本、数值、时钟和验证范围。原版 C++ 源码、库、程序、许可证及服务器地址不随本目录发布。
