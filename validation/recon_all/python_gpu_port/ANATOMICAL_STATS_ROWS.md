# Cortical statistics table rows

`anatomical_stats_rows.py` combines the matched area, thickness, gray-volume
and curvature functions into the ten-column table lines written by
`mris_anatomical_stats -no-th3`. It uses the same column widths and numeric
formatting as FreeSurfer 8.2.0. Inputs are existing white/pial surfaces,
thickness and area maps, annotations and cortex labels.

On the frozen `fs_sub01` reconstruction, a fresh control-host CPU replay compared
the **entire text of every data line** in bilateral aparc, aparc.a2009s and
aparc.DKTatlas white tables and bilateral aparc pial tables. All **346/346**
lines matched exactly, including ROI order, names, whitespace and all ten
columns. The [report](anatomical_stats_rows_cpu_report.json) records every
table and elapsed Python computation time. The
[probe](experimental/anatomical_stats_rows_probe.py) reproduces this check.

The four bilateral `BA_exvivo` and `BA_exvivo.thresh` white tables were also
checked from the Python-generated, byte-exact annotation files. Their **56/56
data lines** matched the official files exactly. These native calls omit
`-cortex`; including the cortex label changes the entorhinal curvature row.
The Python call passes `cortex_label=None` for this fixed branch.

This check starts from official surface and label inputs. The table metadata
and global measures in the header, including brain segmentation volume and
eTIV, are not generated by this function. It is a validated substage, not a
replacement for the full native command or end-to-end reconstruction.
