# sub-01 左侧 pial 全局面积差异定位

## 输入与版本

本诊断比较两次 FNIT 原始 T1 整例输出，候选代码为 `c24852054f3321c1142b1ae88fa3d2bf68329bb3`，基线代码为 `1b8c36d25a68e253a1e59b6d02114890afa467de`。它用于解释优化前后的严格比较失败，不是与官方结果的等效验收。

- `baseline.stats`、`candidate.stats`：两版 `stats/lh.aparc.pial.stats` 的实际内容。
- `difference.json`：输入 SHA-256、逐 Measure/脑区比较、源码 SHA-256、严格比较引用，以及服务器保存面积和选择掩膜的只读复算结果。
- 表面采用 surface RAS，坐标单位 mm；面积 morph 为同序顶点的 float32/mm²；皮层标签和 `.annot` 保留原顶点顺序。

没有修改生产实现、float32 累加定义或验收阈值，没有重跑 GPU 面积算子。

## 逐字段结果

34 个分区的 9 个数值列，共 **306 项全部相同**。列名依次为 `NumVert SurfArea GrayVol ThickAvg ThickStd MeanCurv GausCurv FoldInd CurvInd`。前五列分别为顶点数、mm²、mm³、mm、mm；文件的 `ColHeaders` 没有为后四列声明单位，本报告保留其原数值，不另行假定单位。

十条数值 `# Measure` 中只有以下一条改变，其单位由文件明确声明为 mm²。顶点数、平均厚度和全脑体积表头均相同。

| 字段 | 基线 | 候选 | 差值 |
|---|---:|---:|---:|
| `Cortex, PialSurfArea, Pial Surface Total Area` | 88330.1 mm² | 88330.2 mm² | 0.1 mm²（0.0001132117%） |

严格比较器保留这一失败：44 条数值行中 43 条相同，138 项中 137 项通过。受试目录名和 `AnnotationFile` 路径是输出位置元数据变化，未计作面积误差。

## 差异传播已定位

候选和基线的左侧 pial 坐标、有序三角面、厚度、aparc 注释均完全相同。皮层 label 的 SHA-256 相同；直接复算 `cortex.label ∩ (annotation >= 0)` 的 Boolean 掩膜也逐位相同，两次都选中 97,905 个顶点。

保存的 `lh.area.pial` 有 10,306/105,598 个顶点存在 float32 尾差，其中选中皮层顶点为 9,551 个。最大绝对差为 `4.76837158203125e-7 mm²`，P99 为 `1.1920928955078125e-7 mm²`；原 morph 容差下没有越界顶点。

生产表头使用保存的面积 morph，按顶点顺序逐次 float32 累加，然后以 `:g` 输出六位有效数字。对实际保存输入复算如下。

| 同一皮层掩膜下的面积 | 基线 | 候选 | 候选减基线 |
|---|---:|---:|---:|
| 保存 float32 面积的 float64 合计（诊断） | 88330.3600884527 | 88330.3601054810 | 0.0000170283019543 mm² |
| 生产逐顶点 float32 合计 | 88330.140625 | 88330.156250 | 0.015625 mm² |
| 生产 `:g` 格式 | 88330.1 | 88330.2 | 0.1 mm² |

所以表头的 0.1 mm² 差异包含**顺序 float32 累加及文本舍入的放大**，不能解释为表面形状改变或皮层面积实际相差 0.1 mm²。此定位基于读取两版实际输入的复算；未以平均相关性代替逐项比较，也未宣布整体指标等效。

## 面积尾差来源仍待重复实验确认

`surface_area_gpu.vertex_area()` 使用 float32 叉乘和向量范数计算每面的面积份额，再对三个面角分别调用 CUDA `index_add_` 累加。多条贡献写同一顶点，是需检查的归约位置。`surface_area_gpu.py`、`anatomical_stats_global.py`、`anatomical_stats_file.py`、`surface_stats_cache.py` 的源码在基线与候选之间完全相同，文件哈希见 JSON。

本次复算已经排除了顶点坐标、有序面、注释、皮层选择和表头代码改动。尚未在冻结的同一表面上重复执行 GPU 面积生成，因此不把保存 morph 的尾差归因于随机性，也不将算子候选当作已证实根因。

## 最小 CPU 复算调用

以下调用只读取自产文件，使用原函数产生表头，没有 GPU 计算。两版分别设置 `subject_directory`；`brainvol.stats` 含原全脑体积缓存，`talairach.xfm` 用于原 eTIV 定义。

```python
from pathlib import Path
from fnit.recon_all.anatomical_stats_global import (
    anatomical_stats_global_lines, read_brain_volume_stats,
)

subject_directory = Path("/path/to/fnit_subject")  # 本次自产被试目录
hemisphere = "lh"  # 左半球
brain_volume_statistics = read_brain_volume_stats(
    path=subject_directory / "stats" / "brainvol.stats",  # 保存的 mm³ 体积缓存
)
header_lines = anatomical_stats_global_lines(
    area_map=subject_directory / "surf" / f"{hemisphere}.area.pial",  # float32/mm²
    thickness=subject_directory / "surf" / f"{hemisphere}.thickness",  # 同序 mm 顶点图
    annotation=subject_directory / "label" / f"{hemisphere}.aparc.annot",  # 标签索引
    cortex_label=subject_directory / "label" / f"{hemisphere}.cortex.label",  # 皮层选择
    brainvol_stats=brain_volume_statistics,  # 原全脑体积，不重新估计
    talairach_xfm=subject_directory / "mri" / "transforms" / "talairach.xfm",  # eTIV 变换
    surface="pial",  # PialSurfArea 表头名
    voxel_volume=1.0,  # conformed 网格体素体积，mm³
    cache=None,  # 不复用跨调用缓存
)
print("\n".join(header_lines))
```

返回 `list[str]`，包含十条数值 Measure 及体素体积说明；输入顶点数不符、路径或必需体积字段缺失时抛异常。本次实际直接读取保存 morph 和选择 mask 复算了 float64/float32 两种合计，数值见 `difference.json`，没有用 float64 诊断结果覆盖原输出。

## 后续最小同输入 GPU 实验（尚未执行）

只需在隔离诊断目录中，对一份固定且带哈希的 `lh.pial` 调用现有面积函数至少两次，保存输出，再以同一皮层掩膜复算；无需重跑 white/pial 或整例。所有调用使用同一目标 GPU、原 float32 算法，并同步覆盖读写后的完成时间。

```python
from pathlib import Path
import torch
from fnit.recon_all.surface_area_gpu import area_map

frozen_pial_surface = Path("/path/to/frozen/lh.pial")  # 固定同输入、有序网格
diagnostic_directory = Path("/path/to/isolated_diagnostic")  # 新诊断目录
target_device = "cuda:0"  # 显式目标 GPU，保留原 TF32 策略
diagnostic_directory.mkdir(parents=True, exist_ok=False)
for repetition in range(3):
    torch.cuda.synchronize(device=target_device)  # 开始前同步目标设备
    area_map(
        surface=frozen_pial_surface,  # surface RAS/mm 输入
        output=diagnostic_directory / f"lh.area.pial.repeat{repetition}",  # float32/mm² morph
        device=target_device,  # 全部重复固定同一设备
    )
    torch.cuda.synchronize(device=target_device)  # 包含计算及 morph 写出
```

面积对应原命令 `mris_place_surface --area-map lh.pial lh.area.pial`；表头属于 `mris_anatomical_stats -no-th3 ... -p` 内部步骤，没有单独的表头 CLI。官方对照只能在独立 benchmark 路径中执行。本诊断保留严格失败和原算法，不引入确定性 CPU 替换来牺牲已实测的 GPU 效率。
