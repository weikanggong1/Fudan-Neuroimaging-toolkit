# recon-all 单 T1 的验收门槛

[功能入口](../../../docs/recon_all/README.md) · [验证记录](README.md) · [比较器](compare_complete_subject.py)

当前标准入口只接受一幅原始 T1w。它应从空被试目录连续生成固定的 138 项输出，不得用复制、径向投影或法线射线搜索代替必要的拓扑、white/pial 和球面步骤。`fnit-native-free-run.json` 的 `status=complete` 代表阶段运行、文件存在性和双侧网格质量检查通过；同一报告的 `numeric_validation` 须另行根据独立参考填写。数值验收和执行完成分开判断。

## 运行与完整性

1. 从主页 `environment.yml` 创建新环境、安装当前固定源码编译的原生组件，并用标准入口从原始 T1 开始运行。保存源码提交、T1、权重、资产和二进制 SHA-256、主机、设备、精度设置、阶段耗时及退出状态。
2. 核查两侧拓扑、`white.preaparc`、球面与配准、最终 white、pial、注释和后处理均实际执行。必要阶段失败须抛异常并留运行记录。固定 138 项无缺失；体积网格、surface RAS 与顶点顺序必须自洽。
3. 在没有系统 FSL/FreeSurfer 等预装软件的环境核查进程树、实际读取的文件和动态库。Conda 中按固定源码编译的程序与 FNIT 资产可以存在；独立生成的官方参考不能被候选运行路径当输入使用。

## 严格复现诊断与单阶段回归

使用[严格比较器](compare_complete_subject.py)与同一真实 T1 的独立官方参考对照：

- MRI 与其他体积图：整数图逐体素一致；浮点图绝对误差 ≤1×10⁻⁶；数据类型、仿射与 MGH 头一致。记录不同体素数与首个坐标。
- 表面：有序面、体积几何一致；同索引坐标绝对误差 ≤1×10⁻⁵ mm。顶点数或拓扑不同时，最近邻距离只用于诊断，不计通过。
- 顶点图：面积的限值为 `0.001 + 0.001×|参考值|`，其他图为 `0.005 + 0.001×|参考值|`；逐侧记录 P99、最大差和超阈值顶点数。
- 注释：逐顶点编码、颜色表与名称一致。统计：数据行及 `# Measure` 行的数值绝对差 ≤0.005；列数、行数和文本字段一致。

上述阈值保持不变，用于严格复现诊断。另报 MRI、表面、顶点图、注释和统计各组通过数。比较器已通过官方参考自比 138/138 和厚度/面积定点扰动的负对照。同输入、同网格的算子替换沿用对应算子容差，记录 P99、最大误差和超限位置；整例对官方参考的历史差异与优化新增的差异分别记录。138 项未全部通过不能单独否定有实测依据的 GPU 优化。

## 优化退化与整体指标等效

分别报告三个结论：严格复现、优化是否引入退化、整体指标等效。优化前后使用同一原始 T1、主机与线程预算，检查完整输出、坐标空间、标签语义、网格质量，以及逐脑区和局部误差。针对优化改动的同输入阶段回归先于整例运行。

整体报告必须包含各分区 Dice、双向点到三角面距离、厚度/面积/体积偏差和最差脑区。顶点数或有序面不同时，不进行同索引顶点比较。相关性与文件通过数不能代替这些指标。本项目尚未正式确认整体指标等效阈值；当前结论为 `not_assessed`，既不宣称整体等效，也不把这一待定状态作为性能优化的唯一阻断条件。不得按观察结果降低阈值、删去失败输出或省略必要步骤。

## 资源、速度和跨被试

在相同主机、线程及输入预算下分别计时优化前后及参考流程；单次共享机器观测与稳定速度比区分。GPU 计时同步，整例时间包含模型加载、传输和文件读写。GPU 默认 TF32，SynthStrip、SynthSeg、Talairach affine 与 MNI 非线性阶段的已验证 FP32 例外要在报告中注明；FP16/BF16 不自动启用。显存统一存字节并展示 GB/GiB，外部进程采样与 PyTorch 统计分开；关闭 PyTorch 分配缓存时，后者的 0 不可当成峰值。采样峰值须标明采样间隔，并核查父子进程合计是否低于 20 GB。

至少再用另一例独立真实 T1 检查完整链。[真实非零相交表面](intersection_positive_real_20260929.json)已由 Conda 源码构建程序修复到零，官方同输入配对尚未完成。跨被试检查不能以单个被试双侧或模拟网格代替。
