# 已保存结果和源码之间的边界

本分析仅读取这一次注册、独立只读评分的已保存标量和绑定源码。没有重注册、重复评分、优化反馈或新影像计算。原验收门保持不变。

## 已证实的结果

- 双方原始输入 SHA 相同；官方仅执行两条注册命令，FNIT 仅执行刚体和仿射各一次。每方仿射都使用自己刚体输出的真实 MGH 重读对象。
- 四份 mapped MGH 的源体素、shape、dtype 不变；LTA source/target shape 正确；各自 LTA 与保存头信息的内部几何自洽误差均≤1e-5mm。
- 刚体133点 RMS/max 为5.471e-6/7.742e-6mm；仿射组合几何为2.691e-4/4.487e-4mm，均通过原点位门。
- 刚体 warp 相对L2 2.409e-6通过，但非零支持集差1体素；仿射相对L2 2.588e-5高于1e-5，支持集也差1体素。20项正式检查中17项通过，3项未过。
- 两阶段的13个MGH字段均有11项exact，差异位于 `Mdc` 和 `Pxyz_c`；`delta` 保持0.25mm。刚体方向/中心最大差1.118e-7/3.815e-6，仿射为2.633e-5/3.815e-5。字段差异是记录项，不额外算作上述20项门的失败。
- 固定目标阈值0、移动阈值127.5的体素数、交集数和Dice在双方分别相同。这里只保存统计，没有保存阈值掩膜比较数组，不能由相同计数声称逐体素标签一致。

## Warp 差异与已保存几何的关系

独立评分的两侧使用**同一原始源体素**、同一目标网格、同一个 `resample` 函数、同一chunk/dtype/CPU设置，区别是各自实际保存的 mapped MGH 几何：

`warp = resample(original_values, target_shape, inverse(saved_moving_geometry) @ target_geometry)`。

因此本次评分观察到的warp差异，是不同保存几何经过同一采样运算所得结果；没有双方使用不同评分采样器的证据。保存的LTA/world矩阵确有微差，刚体矩阵max7.629e-6，仿射增量矩阵max1.688e-4、组合矩阵max5.798e-4。不同的微小坐标输入可能在Float运算/插值边界处形成不同的零值判定。

`_sampling.py` 的trilinear实现包含原 `rint` 半体素支持与整数 `FEQUAL` shortcut，输出存储为Float。该源码提供了近边界差异的机制，但**本次结果没有保存那1个支持集体素的位置、双方数值或局部邻域**，所以不能证明具体由哪一个shortcut、边界或插值项触发，也不能宣称它只是某个已量化的极小正数。支持集门检查任意非零值，和127.5的二值掩膜统计不是同一指标。

这个评分是共享FNIT采样器对双方保存几何的比较；官方两命令使用 `--mapmovhdr`，没有生成作为独立原软件重采样oracle的warp。不能把本结果写成PyTorch与官方MRI重采样器同输入、同矩阵的数值对照。

## 保存头信息尾数是否是全部原因

各自LTA与自己的保存MGH内部最大自洽误差分别为刚体9.537e-7/1.907e-6mm，仿射2.861e-6/0mm。源码和结果都确认Float `MATRIX_REAL`、`Mdc/Pxyz_c` 保存边界存在，且原 `mapmovhdr` 不把仿射后的方向强行归一化。

这证明有保存/表示尾数，**不能证明所有几何差异都来自保存**。官方和FNIT的LTA本身已经不同，仿射输入也继承各自略有不同的刚体头信息；没有进行交换某一变量的额外评分，所以未把求解结果差与MGH保存差作实验性因果拆分。

## 初始化、采样与求解器的未定归因

绑定原软件默认是Float图像/解析A/QR，Double小矩阵状态；本候选保持这些实际类型。原VNL Float QR与本候选PyTorch QR、串行/并行Float reduction、Double质心求和、4×4 Schur库仍可能有尾差。源码还涉及初始B-spline和每轴Float金字塔，局部合同通过并不等于真实输入中每个中间数组都通过原软件比较。

没有官方same-A/b、初始质心、各层图像或内部矩阵trajectory捕获。因此：

1. 有证据：最终保存的几何差很小，经过同一评分采样器形成了上述warp差异。
2. 有证据：仿射输入的两份刚体头信息不是bitexact，后续仿射不是同内部状态起点的solver对照。
3. 尚未证明：哪个初始化、图像准备、QR/reduction或参数更新最先分叉；不能将VNL/PyTorch差异直接叫作已确认bug。
4. 尚未证明：那1个支持集体素的局部机制和幅值；不能凭计数把它当作最终脑区标签误差。

真实FNIT两阶段都是2层×每层5次更新，4个level全部 `iteration_budget_exhausted`，未达到0.01停止距离。每层停止定义和预算是固定源码策略，报告没有把耗尽预算称为收敛。
