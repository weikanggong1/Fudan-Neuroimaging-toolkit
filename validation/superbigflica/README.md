# SuperBigFLICA 真实数据验证

本次使用 500 名真实 UKB 被试的完整 VBM、FA 和 MD 掩膜影像，验证公开 `run_superbigflica` API、连续/分类混合目标、留出测试、固定模型推理和成分图。机器可读记录为 [队列与匹配](cohort_real500.json)、[CPU 完整流程](cpu_real500.json)和[原版连续目标数值比较](upstream_continuous_real8.json)。输入、模型与测量源码的 SHA-256 均由报告保存；公开报告不含被试 ID、逐人表型或原始影像。

## 输入与设置

影像沿用 BigFLICA 的每被试目录结构。CSV 行顺序被打乱，再按字符串 ID 匹配 500 名模态齐全且两项表型有效的被试；两类疾病标签人数为 104 和 396。影像每模态网格为 `91 × 109 × 91`，使用完整掩膜：

| 模态 | 掩膜体素数 |
|---|---:|
| VBM | 157,901 |
| FA | 222,257 |
| MD | 222,261 |

连续目标 `p20023_i0` 为 [UKB field 20023：匹配反应时间（毫秒）](https://biobank.ndph.ox.ac.uk/ukb/field.cgi?id=20023)，不是智商。分类目标为原疾病表中的 `Incident_I9_HYPTENS`。从已有随机排列的 30,000 人队列中取前 500 名同时具有两项有效表型的被试；这次核验不含缺失标签。缺失标签、三类别目标和测试标签独立性另由定向功能测试覆盖。

训练/验证/测试为 **300/100/100 人**，按疾病标签分层，随机种子 `0`。使用 `3` 个成分、`20` 个 epoch、批次 `32`。影像与连续表型的均值、标准差仅由训练集估计；每轮只用验证损失选模，测试集在模型固定后评估。当前观测中最佳 epoch 为 `18`。

## 留出预测结果

连续预测已还原为毫秒。各集合的有效标签数及完整指标见 CPU JSON：

| 集合 | 人数 | MAE（ms） | RMSE（ms） | Pearson r | R² |
|---|---:|---:|---:|---:|---:|
| 训练 | 300 | 63.41 | 87.10 | 0.6777 | 0.1670 |
| 验证 | 100 | 70.29 | 90.60 | 0.2869 | 0.0255 |
| 测试 | 100 | 75.50 | 98.59 | 0.1595 | 0.0018 |

| 集合 | 人数 | Accuracy | Balanced accuracy | Macro F1 | ROC AUC |
|---|---:|---:|---:|---:|---:|
| 训练 | 300 | 0.7900 | 0.4979 | 0.4413 | 0.8202 |
| 验证 | 100 | 0.7900 | 0.5000 | 0.4413 | 0.6263 |
| 测试 | 100 | 0.7900 | 0.5000 | 0.4413 | 0.6492 |

本配置测试集的 balanced accuracy 为 0.5。ROC AUC 衡量输出概率的排序，与默认最大概率标签的分类效果不同；这组结果应作为当前队列及参数的实测记录。分类预测是 FNIT 扩展，原 SuperBigFLICA 源码不提供分类头。

## 与原版连续模型的数值比较

使用上述真实训练集中的 **8 人、三个完整模态掩膜**，固定相同的已训练空间权重、模态权重、连续预测头与 BatchNorm 统计，关闭 dropout，并使用完整连续标签。在原作者代码的独立对照中计算前向、四项损失和反向梯度；源码固定到 `6695b638802aab50f43f889e97af223f8191018e`。

| 比较项 | 最大绝对误差 |
|---|---:|
| 共享成分 | 0 |
| 连续预测 | 0 |
| 三模态重建 | 5.96e-08 |
| 总损失与四项损失 | 2.38e-07 |
| 全部检查的梯度 | 8.73e-10 |

所有比较通过 `rtol=1e-4, atol=1e-5`。该比较验证固定参数下的连续模型计算；500 人训练采用混合目标与验证损失选模，不是原版独立训练后的模型一致性比较。原版对照仓库未提供明确再分发许可，FNIT 依据论文独立实现，未收录其源码。

## 输出、推理与资源观测

成分矩阵为 `500 × 3`。三个模态合计 18 张 z-stat/阈值 NIfTI 均为 float32、数值有限、掩膜外为零；z-stat 影像与保存的成分数组一致。固定模型单被试推理相对训练流程评估的成分最大差为 `2.1e-07`；反应时间最大差 `9.33e-06` ms，分类概率最大差 `1.49e-08`。

| 计时或资源 | CPU 观测 |
|---|---:|
| 匹配、读取与标准化 | 130.68 s |
| 训练、验证选模与预测 | 193.14 s |
| 空间统计与脑图 | 13.15 s |
| 公开 API 全流程 | 338.47 s |
| 验证进程峰值 RSS | 1.14 GiB |

这次记录来自共享 CPU 主机的 8 线程单次运行，包含输入和输出读写。GPU 全流程时间与峰值显存尚未测量；定向 CUDA 测试不能替代这项真实队列基准。空间图输出前检查成分设计矩阵的 float32 有效秩；CUDA 训练与空间统计按 `max_gpu_gb` 调整实际批次和体素块。

功能接口、完整参数与示例见 [SuperBigFLICA 功能页](../../docs/superbigflica/README.md)。
