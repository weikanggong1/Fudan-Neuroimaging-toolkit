# SuperBigFLICA 真实数据验证

使用 **5,000 名真实 UKB 被试、20 个共享成分、VBM/FA/MD 完整掩膜**，验证公开 `run_superbigflica` API、连续/二分类混合目标、留出测试、固定模型推理、空间图和自动绘图。机器可读记录为 [队列与匹配](cohort_real5000.json)、[H100 完整流程](gpu_real5000.json)和[原版连续模型数值比较](upstream_continuous_real8.json)。输入、模型、源码和最终绘图文件的 SHA-256 均由报告保存；公开报告不含被试 ID 或逐人表型表。

## 输入与设置

从已有随机排列的 30,000 人队列中取前 5,000 名模态齐全且两项表型有效的被试。CSV 行顺序打乱后，按字符串 ID 与影像目录匹配；疾病类别 0/1 人数分别为 3,934/1,066。影像沿用 BigFLICA 的每被试目录结构，各模态网格为 `91 × 109 × 91`：

| 模态 | 完整掩膜体素数 |
|---|---:|
| VBM | 157,901 |
| FA | 222,257 |
| MD | 222,261 |

连续目标 `p20023_i0` 为 [UKB field 20023：匹配反应时间（毫秒）](https://biobank.ndph.ox.ac.uk/ukb/field.cgi?id=20023)。二分类目标为 `Incident_I9_HYPTENS`。本次真实基准没有三类及以上标签；多分类、缺失标签和测试集隔离由定向 CPU/CUDA 功能测试覆盖。

训练/验证/测试为 **3,000/1,000/1,000 人**，按疾病标签分层，随机种子 `0`。使用 20 个成分、批次 64、dropout 0.2、随机初始化，完整执行 **50 个 epoch**。影像与连续表型的均值、标准差只由训练集估计；分类使用 `class_weight="balanced"`。训练集类别 0/1 人数为 2,360/640，冻结类别权重为 0.635593/2.34375。每轮按验证监督损失选模，最佳 epoch 为 **5**，随后评估测试集。

训练和输出使用 float32，CUDA 默认 TF32；空间统计使用 float64。没有 PCA 或 MIGP 初始化。

## 当前实现的缓存与数值处理

公开训练和单被试推理显式固定 float32，不随全局默认 dtype 改变。空间统计把训练成分在 float64 中逐列中心化、缩放，再按来源 float32 的机器精度检查有效秩；保存的原成分与预测权重单位保持一致。CPU/CUDA 的 Student-t 转 z 使用相同双侧概率下限。

显存预算扣除调用方已有分配，并预留模型/优化器与批次空间；能容纳完整标准化输入时自动缓存到 GPU。缓存分配失败或预算不足时使用 HDF5 流式读取。`input_cache_s` 单独记录缓存前载时间。缓存路径的空间回归先切体素块，再提取训练行，直接使用 float64 张量统计。

脑图按体素实际毫米尺寸显示切面比例；ROC 摘要的每类结果放入 `class_auc`，与 `macro_auc`、`micro_auc` 汇总字段分开保存。

## 定向回归检查

[效率与一致性报告](efficiency_real5000.json)记录 **60 项测试通过，0 项失败**，覆盖以下五类问题：

- 成分单位造成的空间回归数值问题，以及 float32 舍入造成的错误满秩判断。
- CPU/CUDA Student-t 转 z 在极端尾部的概率下限差异。
- 全局默认 float64 对公开训练和单被试推理精度的影响。
- 非等体素网格脑图的切面比例变形。
- 类别名与 ROC 的 macro/micro 汇总字段冲突。

另核对 GPU 缓存的被试顺序与重复索引、预算不足及分配失败的 HDF5 回退、张量空间回归，以及共享 BigFLICA 回归测试。功能测试中的生成输入用于错误重现，真实性能记录来自上述 UKB 队列。
