# SuperBigFLICA 真实数据验证

使用 **5,000 名真实 UKB 被试、20 个共享成分、VBM/FA/MD 完整掩膜**，验证公开 `run_superbigflica` API、连续/二分类混合目标、留出测试、固定模型推理、空间图和自动绘图。机器可读记录为 [队列与匹配](cohort_real5000.json)、[H100 完整流程](gpu_real5000.json)和[原版连续模型数值比较](upstream_continuous_real8.json)。输入、模型、源码和最终绘图文件的 SHA-256 均由报告保存；公开报告不含被试 ID 或逐人表型表。

## 输入与设置

从已有随机排列的 30,000 人队列中取前 5,000 名模态齐全且两项表型有效的被试。CSV 行顺序打乱后，按字符串 ID 与影像目录匹配；疾病类别 0/1 人数分别为 3,934/1,066。影像沿用 BigFLICA 的每被试目录结构，各模态网格为 `91 × 109 × 91`：

| 模态 | 完整掩膜体素数 |
|---|---:|
| VBM | 157,901 |
| FA | 222,257 |
| MD | 222,261 |

连续目标 `p20023_i0` 为 [UKB field 20023：匹配反应时间（毫秒）](https://biobank.ndph.ox.ac.uk/ukb/field.cgi?id=20023)。二分类目标为 `Incident_I9_HYPTENS`。本次真实基准没有三类及以上标签；多分类、缺失标签和测试集隔离由定向 CPU/CUDA 功能测试覆盖。

训练/验证/测试为 **3,000/1,000/1,000 人**，按疾病标签分层，随机种子 `0`。使用 20 个成分、批次 64、dropout 0.2、随机初始化，完整执行 **50 个 epoch**。影像与连续表型的均值、标准差只由训练集估计；分类使用 `class_weight="balanced"`。训练集类别 0/1 人数为 2,360/640，冻结类别权重为 0.635593/2.34375。每轮按验证监督损失选模，最佳 epoch 为 **5**，随后评估测试集。

训练和输出使用 float32，CUDA 默认 TF32；空间统计使用 float64。没有 PCA 或 MIGP 初始化。

指标描述本次队列、划分和参数的预测表现。分类预测为 FNIT 扩展，原 SuperBigFLICA 连续模型没有分类头。

记录来自共享 NVIDIA H100 PCIe、8 个 CPU 线程的单次运行，包含影像读写与自动绘图；启动时 GPU 利用率为 100%。GPU allocation 为 PyTorch 张量分配峰值。最终添加显示名与单位后的独立重画耗时 7.11 s，单独记录于报告。

缓存按被试切分 HDF5 块，批次逐行读取后组成 float32 张量。同一固定 64 行 VBM 读取测试中，两次 HDF5 fancy indexing 耗时 0.410–0.851 s，逐行读取再堆叠耗时 0.037–0.040 s，输出完全一致；改动前后的前五轮六项聚合损失也逐值一致。这是特定缓存读取测试，完整流程时间以上表为准。

## 空间图与冻结推理

成分矩阵为 `5,000 × 20`，训练成分秩为 20，含截距的空间回归设计矩阵秩为 21。三个模态合计 120 张 z-stat/阈值 NIfTI 均为 float32、数值有限、掩膜外为零；z-stat 影像与保存的 z 数组一致。空间图输出前检查成分有效秩，CUDA 训练与空间统计按 `max_gpu_gb` 调整批次和体素块；本次有效批次为 64。

| 固定模型单被试推理，对照批次评估 | CPU | CUDA |
|---|---:|---:|
| 成分最大绝对差 | 1.92e-05 | 1.91e-05 |
| 反应时间最大差（ms） | 0.00457 | 0.00456 |
| 分类概率最大差 | 2.32e-05 | 2.31e-05 |

固定模型 CPU 与 CUDA 单被试成分最大差为 4.84e-08。

## 与原版连续模型的数值比较

使用本次训练集中的 **8 人、20 成分、三个完整模态掩膜**，固定相同的已训练空间权重、模态权重、连续预测头与 BatchNorm 统计，关闭 dropout，并使用完整连续标签。在原作者代码的独立对照中计算前向、四项损失和反向梯度；源码固定到 `6695b638802aab50f43f889e97af223f8191018e`。逐项数值与源码校验见 [连续模型报告](upstream_continuous_real8.json)。

| 比较项 | 最大绝对误差 |
|---|---:|
| 共享成分 | 0 |
| 连续预测 | 0 |
| 总损失与四项损失 | 0 |
| 三模态重建 | 1.19e-07 |
| 全部检查的梯度 | 1.49e-08 |

所有比较通过 `rtol=1e-4, atol=1e-5`。该比较覆盖固定参数下的连续模型计算；本次 5,000 人训练使用混合目标与验证损失选模。原版仓库未提供明确再分发许可，FNIT 依据论文独立实现，未收录其源码。
