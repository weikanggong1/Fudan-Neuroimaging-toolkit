# Saved-basis first392 bending 数值控制（公开草案）

## 1. 功能简介

本控制从已保存的 FNIRT bending basis 和 half-diagonal 成员，按声明的三维 X-fast 顺序计算 392 个系数的完整 3D 六项自重叠参考值，并与已保存的成熟 half-diagonal 乘 2 结果逐词比较。它是数值顺序控制，用来量化保存 basis 上的浮点尾差。

本次控制没有生成 basis，没有调用 FNIT 配准、采样、梯度、Hessian、PCG、GPU 或 native kernel。

## 2. 输入、输出与调用边界

输入是 18 个保存的 Float64 derivative basis 成员、1 个保存的 half-diagonal、固定几何元数据（系数形状 7×8×7、knot spacing 5×5×5、层级体素尺寸 8 mm）。只恢复声明的 19 个成员；输入目录中其他成员保持未读取。

输出是 392 个 Float64 参考值、392 个保存值，以及位级差异统计。公开报告只保留聚合统计，不发布 basis、参数数组、影像、服务器地址、私密文件名或哈希。

## 3. 方法与运算顺序

六项顺序为 `XX, XY, XZ, YY, YZ, ZZ`，Hessian 因子为 `2, 4, 4, 2, 4, 2`。每个系数使用完整 19³ 支持域，按 Z×Y 后 X 的 X-fast 顺序累加；保存的 diagonal 是 half 值，只乘 2 一次。参考实现使用 Python Float64 标量累加，没有替代方法或顺序搜索。

## 4. 真实结果

| 指标 | 结果 |
|---|---:|
| 比较词数 | 392 |
| 位差词数 | 392 |
| signed-zero 差异 | 0 |
| 首个差异位置 | X-fast index 0 |
| 最大绝对差 | 1.1926223897340549 × 10⁻¹⁸ |
| 相对 L2 差 | 3.2072928628915523 × 10⁻¹⁵ |
| 完整 19³ 支持点 | 16,132,368 |
| 六项自重叠点积 | 2,352 |

所有词均有位级差异，但差异量级处于浮点舍入尾差范围，和累加顺序及乘法舍入造成的结果一致。该观察不等于已证明某个 native 组件、完整 Hessian、PCG 轨迹或最终影像相同。

## 5. 控制状态与耗时

控制仅执行一次；19 个成员恢复、一次六项 3D 参考、一次与保存值比较均按固定上限完成。参考计算耗时约 1.074 秒，受监督控制总耗时约 1.47 秒，峰值 RSS 约 18.2 MB。时钟包含 Python 控制和安全收据处理，不能作为生产性能或并行效率基准。

源文件、输入绑定和控制文件在执行前后保持一致；CPU 亲和性、文件描述符、共享锁和受监督进程均已释放。控制成功只表示本次保存 basis 数值比较完整。

## 6. 范围限制

- 这是 saved-basis 的 392 项参考，不是已安装 basisfield/native BendEnergyHess 的指令级追踪。
- 不能由此推出 1177 项组合对角、PCG、采样、梯度/Hessian、配准终点或 GPU 结果。
- 六项因子、三维支持域和累加顺序在同一控制中同时改变，不能单独归因某一项。
- 该结果不修改生产 CPU/GPU 路径，也不构成默认 API 验收或速度结论。
- 未生成新的脑图；本报告只呈现数值聚合统计。

## 7. 复现与引用

复现需要项目已批准的保存 basis 控制包和相同的 Float64 运行时；公开材料不包含原始数组。相关 FNIRT 说明、保存算子资格记录和上游 FSL 实现应分别引用项目公开文档及 FSL 官方资料。任何 native 组件比较都需要另行授权、另行冻结和独立控制。
