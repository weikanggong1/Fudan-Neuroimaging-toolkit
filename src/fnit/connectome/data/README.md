# MRtrix SIFT2 direction asset

`mrtrix_sift2_1281.npz` contains the fixed 1,281-direction grid used by MRtrix
`tcksift2 3.0.3-103-g026e850d`: unit XYZ directions (`float64`, 1281 × 3),
the antipodally identified convex-hull adjacency in CSR form (`int32` offsets,
`int16` indices), and FMLS spherical-integration weights (`float64`, 1281).
The weights solve the source's even real spherical-harmonic calibration through
degree 50 by unpivoted QR. They are not uniform solid-angle weights.

Generated by `tools/generate_mrtrix_sift2_directions.py` from MRtrix3 commit
[`026e850d`](https://github.com/MRtrix3/mrtrix3/tree/026e850d). Source files:
[`predefined.cpp`](https://github.com/MRtrix3/mrtrix3/blob/026e850d/src/dwi/directions/predefined.cpp)
(SHA256 `176bd8f40f35fd229633fdd90be28c36400f94ae105c38513ae7f96f8ed574ad`),
[`set.cpp`](https://github.com/MRtrix3/mrtrix3/blob/026e850d/src/dwi/directions/set.cpp)
(SHA256 `609e092f82064eab70521d95c171d9f392d41153a95651e678eee6134b0585f1`),
and [`fmls.cpp`](https://github.com/MRtrix3/mrtrix3/blob/026e850d/src/dwi/fmls.cpp)
(integration-weight algorithm). The resulting NPZ SHA256 is
`7c510ebd2ce05a5eed75f55544323168e2fe807de81b4fbefa079d8db812a52d`.
